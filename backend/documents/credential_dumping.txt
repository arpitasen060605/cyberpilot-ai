Credential Dumping- Credential dumping is the process where cybercriminals illegally extract account credentials (usernames, passwords, and hashes) from a system's memory or storage.
Attackers use these dumped credentials to escalate their privileges and move sideways through a network.

Where Credentials Hidden
System Memory: Found in active memory processes like the Local Security Authority Subsystem Service (lsass.exe) on Windows.
SAM Database: Stored in the Security Account Manager registry hive containing local user password hashes.
NTDS.dit File: Located on Active Directory Domain Controllers holding the database of all network users and hashes.
Hardcoded Files: Hidden in plain-text inside configuration scripts, group policy preferences, or web browser data stores.

Common Extraction Methods
LSASS Dumping: Attackers use tools to read and copy the operating memory of the authentication process.
Registry Exporting: Attackers use built-in commands to copy the SAM and SYSTEM registry keys to a file.
Volume Shadow Copies: Attackers clone the hard drive partition to safely copy locked system files like ntds.dit.
DCSync Attacks: Attackers trick a Domain Controller into synchronizing and sharing its password hashes voluntarily.

How to Detect Dumping
Process Monitoring: Alert on unauthorized tools (like mimikatz.exe) running or system utilities renaming to bypass blocks.
Memory Access Alerts: Track suspicious programs trying to open a read handle to the lsass.exe process.
Event ID 4656 / 4663: Monitor these security logs for unexpected access requests to registry keys or security files.
Committed Minidumps: Watch for files ending in .dmp created by task manager or administrative tools.
